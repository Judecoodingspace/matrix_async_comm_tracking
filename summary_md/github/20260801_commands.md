# GitHub CLI Commands for the Tracklet Transition

Run from the authenticated project terminal.

Preferred idempotent command:

```bash
bash scripts/manage_github_tracklet_transition.sh
```

The script updates matching issues when they already exist and creates them
otherwise. The equivalent individual commands are retained below for audit.

```bash
REPO=Judecoodingspace/matrix_async_comm_tracking

gh auth status
gh repo view "$REPO"

gh label create experiment --repo "$REPO" --color 1D76DB --description "Formal experiment tracking" --force
gh label create analysis --repo "$REPO" --color 5319E7 --description "Experiment analysis and interpretation" --force
gh label create completed --repo "$REPO" --color 0E8A16 --description "Completed and documented" --force
gh label create current-stage --repo "$REPO" --color FBCA04 --description "Active research stage" --force
gh label create research-decision --repo "$REPO" --color D4C5F9 --description "Research scope or direction decision" --force

gh issue list --repo "$REPO" --state all --limit 100

gh issue create --repo "$REPO" \
  --title "Milestone: observation-level asynchronous fusion complete" \
  --body-file summary_md/github/20260801_observation_level_milestone_issue.md \
  --label experiment --label analysis --label completed --label research-decision

gh issue create --repo "$REPO" \
  --title "exp_20260801_002: incremental local-tracklet update foundation" \
  --body-file summary_md/github/20260801_incremental_tracklet_stage_issue.md \
  --label experiment --label current-stage
```

Commit the tracked research records from the real Git worktree:

```bash
git switch -c exp/20260801-002-incremental-tracklet-foundation
git add \
  GLOSSARY.md \
  ascii_diagrams/ \
  mermaid/ \
  src/tracking/matrix_local_tracklet.py \
  scripts/phase3_matrix_incremental_tracklet_foundation.py \
  scripts/prepare_matrix_local_tracklet_osnet_cache.py \
  scripts/manage_github_tracklet_transition.sh \
  summary_md/ \
  tests/test_matrix_incremental_tracklet.py
git commit -m "feat: add incremental local tracklet foundation audit"
git push -u origin exp/20260801-002-incremental-tracklet-foundation
```

After issue creation, record the returned URLs in
`summary_md/current_status.md`. Do not commit `outputs/`, datasets, caches, or
weights.
